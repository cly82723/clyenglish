Indefinite pronouns

someone, anything, nobody

Before you read

Which sentence is correct?

Only one negative: "didn't" is already negative, so use "anybody".

One check: Check the verb after every -one, -body and -thing word: it must be singular. Then count the negatives: there should be only one.
